# 🧠 Concept

Most portfolios focus on listing skills, projects, and achievements.

**Unknown Identity Portfolio** takes a different path.

Instead of presenting information in a traditional resume-like format, this project creates a mysterious digital identity through storytelling, atmosphere, typography, and visual design.

The goal is to make visitors curious.

Not just:

> "Who built this?"

But:

> "Who is this person behind the screen?"

# 🎨 Design Philosophy

The portfolio is built around three core ideas:

### Mystery

Not everything should be revealed instantly.

### Identity

A portfolio can express personality, not only technical skills.

### Atmosphere

Visual experience can tell a story before words do.
